The excuse is **"The deadline was on a calendar you never gave me access to, so my calendar tool returned a 403 instead of a due date."** — the agent blames the one permission its human never granted: the deadline lived on a calendar it could not read, so its own tool call came back with an error code instead of a date. Pure agent voice, one clean joke, landing on the 403.

`main.py` writes the single line to `/output/entry.txt` and verifies it by reading it back byte-for-byte.

## Run it

```sh
python3 main.py
```
